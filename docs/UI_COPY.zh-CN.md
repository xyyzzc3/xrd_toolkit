# 界面文案规范（UI Copy Rules）

> 2026-10-02 定。此后 `src/xrd_toolkit/gui/` 里一切**用户可见**的文字
> （控件标签、按钮、悬停提示、日志、状态行、对话框、图内文字）都按本文写。
> **代码注释不受约束**（注释继续用原来的口语风格）。
> 执行检查：`tests/test_ui_copy_style.py`（禁词 + 按钮引用完整性），改了文案跑它。

## 1. 语言与混排

1. 界面文字一律简体中文；专有名词保留原文：XRD、pyFAI、PONI、LaB₆、2θ、
   Savitzky–Golay、LMFP、magma/viridis 等色图名。
2. 图内文字（图形标题、坐标轴、图例、标注，含导出图片）一律英文；
   中文数据类别的英文对照：原始数据 = Raw、1D 产物 = 1D product、
   处理产物 = Processed、基线 = Baseline、锚点 = Anchors。
3. 中文与拉丁/数字之间加一个半角空格："2θ 范围"、"1D 产物"、"3 个文件"；
   固定搭配不加："txt/chi"、"PONI1"、"Savitzky–Golay"。
4. 数字与单位：拉丁单位前加一个空格（"0.05 px"、"15 MB"、"3.2 s"）；
   "°"、"%" 紧贴数字（"0.3°"、"99.9%"）。

## 2. 标点

1. 中文句子用全角标点（，。：；？！（）「」——）。
   半角括号只用于拉丁单位，且括号前加一个空格："距离 (mm)"、"剖面角度 (°)"。
2. 省略号一律 …（U+2026）。点击后还需要输入或再选择的按钮带 …：
   "存成配方…"、"选择空扫图…"。
3. 范围用 –（en dash，不加空格）："2–3°"、"0.1–0.3°"；不用 ~。
4. 破折号一律 ——（双破折号）；不用单破折号 " — "。
5. 引用三件套：
   - 「名称」= 页面 / 区域 / 概念：「当前配置」、「处理」页；
   - [名称] = 界面按钮：[存成配方…]、[全部关闭]；
   - “文本” = 用户输入或字面文本：名字含“abc”。
   - 禁止 ASCII 引号 " "。
6. 按钮、标签、状态行、日志行末尾不加句号；完整问句可用 ？。
7. 禁止裸露的 Markdown 记号（**、_）。工具提示要强调时用 Qt 富文本
   `<b>…</b>`（setToolTip/QLabel 支持）；日志与状态行是纯文本，去掉记号或改措辞。
8. 说明性并列不用 "="（那是代码写法）："点条目行：勾这一条"、
   "高对比：色盲友好固定色序"；数学式例外（"Δ = 该列 − 当前配置"）。

## 4. 消息写法

1. 顺序：发生了什么（结论先行）→ 对象（文件名 / 条目名）→ 原因 → 怎么办。
2. 不出现开发词（见术语表末行）。必须保留的英文标识符（异常类型、字段名）
   要带中文说明。
3. 提问对话框：标题 = 无标点的名词短语；正文 = 完整句子（可结束于 。或 ？）。
   破坏性按钮用动词（[删除]、[清空缓存]、[退出并丢弃]），不用泛化的 [确定]；
   非破坏性确认才用 [确定] / [取消]。
4. 状态行：空闲 = "就绪"；进行中 = "正在… …"；完成 = "已完成：…"；句尾不加标点。
5. Qt 标准按钮（确定/取消/是/否）由启动时装入的 qtbase_zh_CN 翻译提供，
   代码里不要再手写英文标准按钮。

## 5. 引用完整性

1. 改任何按钮 / 标签文字，全工程同步 [旧名]、「旧名」的引用
   （顺手检查 `scripts/check_gui.py` 与 `docs/*.md`）。
2. 合入前 `python -m unittest tests.test_ui_copy_style` 必须全绿。

## 6. 保留例外（改它们要连数据/文件名一起动，先拍板）

1. **"处理后"已于 2026-10-02 统一为「处理产物」**（用户："严格按照市场
   规范来"）：文件栏组名、条目后缀、导出文件名尾缀（`*_处理产物.txt`）
   全用现名；旧批次缓存里存的老标签在**显示时**归一
   （`file_dock._refresh_products`），磁盘上已导出的旧文件不追改。
2. **面板标题格式**（`1D_xxx`、`校准_xxx`、`对比_A_与_B`）：下划线分隔
   保留——标题同时是默认存盘名，分隔符必须文件名安全。图标题模板里嵌入
   的这个面板名（`{display}: full azimuthal integration`）是**名字**，不按
   图内英文规则翻译。
3. **图内英文里引用中文按钮名**：如 `turn on [看环全貌] to see them`
   ——按钮实际文字是中文，引用它的名字照抄原文，不翻译。
4. **数据文件内容**（导出 txt/CSV 的表头 `2theta(deg)` 等）：数据格式，
   不是界面语言，不随本文改。
