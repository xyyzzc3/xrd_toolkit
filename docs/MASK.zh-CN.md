# Mask（遮罩）快速上手

> 适用于当前开发版（v0.1.6 未发布）。Mask 的做法是：
> **在 2D→1D 积分之前**把 beamstop、模块缝、坏点遮掉，并生成一条
> 「Mask 后的 2D」数据；之后再用它做 1D、对比、处理。坏点不会被改写，
> 只是不参与方位角平均。

![Mask 工作台](../showcase/gui/gui_mask.png)

## 1. 什么时候要 Mask

- 探测器有**固定坏点/热像素团**：会在 1D 上抬起背景或制造假峰；
- **beamstop / 模块缝 / 探测器边缘**：会压低低角强度；
- 明显的固定寄生散射斑点。

**不要遮真实衍射环**（包括 Al 基片的峰）：整条环被遮掉，等于把这个
2θ 的真实强度删掉，1D 上会出现坑，拟合变好是假象。基片峰应当按第二相
建模，Mask 只处理探测器问题。

判断口诀：坏点在**像素坐标**上固定、面积小、跨帧逐位相同；真实环在
**2θ** 上固定、跨方位角连续。

**不要**用 [整环离群（实验性）] 去遮真实衍射环：它会把强环的方位起伏
当成坏点（真实 LMFP 帧上会沿环误标约 18k px）。它只作实验性参考。

## 2. 打开工作台

1. 先在文件栏导入并勾选原始数据（Mask 只认文件栏里的原始图）；
2. 点工具栏 **[Mask]**（在 [校准] 右边）：中央绘图区换成 Mask 工作台，
   **参数坞和日志坞自动收起**，把地方让给画布；工作台会载入勾选的第一张；
3. 顶部「图像」下拉可以换图；[载入勾选图像] 可重新载入当前勾选的图；
4. 再点一次 **[退出 Mask]**（或关闭工作台的 ×，或按 Esc）回到分析模式，
   参数坞/日志坞恢复成进入前的样子。

工作台底部有一行消息（最近一次自动检测/配方/生成的结果）+ 状态行
（文件名、尺寸、mask 像素数/百分比、当前工具、缩放倍数）。

## 3. 画 mask 与看大图

- **画笔 / 橡皮**：按住左键拖；笔刷大小在「笔刷 xx px」里调；
- **矩形**：拖出一个矩形，松开后整块遮掉；
- **撤销 / 清空**：就在画笔工具旁边；撤销最多 12 步；
- **孤立坏点（局部）**：15×15 局部中值 + 小连通域，专抓孤立亮团/坏点簇，
  不碰真实衍射环（生产路径）；
- **整环离群（实验性）**：按径向环带找离群像素（与 GSAS-II 的自动
  spot mask 同一思路）；真实环可能被误标，跑完要用橡皮/撤销修。

**看大图**：点亮 [放大镜] 后，滚轮以光标为中心缩放（每格 10%）、
左键拖 = 框选放大；熄灭后左键回到画笔。中键（Mac 触控板用 ⌥ 或 Shift +
左键）拖动平移；**[复位视图]**（或 **Home** 键，与主窗口一致）一键复位。
状态栏在放大时显示「缩放 N.N×」。

遮罩永远是全分辨率，只有显示会按视图降采样（块内取最大 / 任一），
缩到全图时孤立坏点也不会被平均掉。

图中半透明色块 = 将被遮掉的像素，颜色标出来源：

| 颜色 | 来源 |
|---|---|
| 红 | 画笔 / 矩形（手动） |
| 青 | 孤立坏点（局部） |
| 绿 | 整环离群（实验性） |

自动检测跑完会记下新增的像素：点 **[查看改动]** 可缩放到改动处
（重复点按依次看各处）；点 **[预览效果]** 会画 mask 前/后的 1D 对比——
真峰不动、假峰消失，才说明这次自动检测合理。

## 4. 生成「Mask 后的 2D」

先选生成范围：

| 范围 | 作用 |
|---|---|
| 当前图像 | 只给工作台里这张图生成一条 Mask 2D |
| 勾选的 N 个文件 | 给文件栏里勾选的每个原始图各生成一条（同探测器、同形状） |

点 **[生成 Mask 2D]**。生成后：

- 文件栏出现 **「Mask 后的 2D」** 组，条目名形如
  `LMFP_1-00029.tif · Mask2D（配方文件名）`；
- 同一张图 + 同一 mask 重复生成会复用同一条，不会堆重复条目；
- 生成后 mask 没再改，按钮会变成「已生成（无改动）」并置灰，
  改一笔就恢复可点；
- **原始图不会被改写**，mask 像素仍是原值；Mask 2D 只是“原图 + mask”的
  引用/小 manifest（`<缓存>/masked2d/*.mask2d.npz`），不复制 16 MB 像素。

![Mask 后的 2D 与 2D 面板](../showcase/gui/gui_mask2d.png)

## 5. 用 Mask 2D 做 2D / 1D

- **双击**「Mask 后的 2D」条目 = 打开 2D 面板（原始像素 + mask 叠加）；
- **右键 → [打开 1D 图]** = 按这份 mask 积分，1D 产物挂在同一条目下；
- 遮罩与未遮罩的 1D 是**两个不同的源**，可以同时存在、并排对比；
- 对比 / 热图 / 批量处理里，Mask 2D 和原始数据一样可勾选、可出图。

> 标定的环检测仍然用**原图**，不套 mask；mask 只作用于 2D→1D 积分。

## 6. 配方与通用掩膜

Mask 分两种文件，概念与「处理」页的配方一致：

- **[导出配方…]**：存成 `.mask.npz`，包含 mask、**来源分层**（哪块是
  手动/孤立坏点/整环离群）和元数据（来源图、形状、几何名、程序版本）。
  默认路径 `outputs/masks/<几何名>_mask.mask.npz`；
- **[导入配方…]**：读回 `.mask.npz`，来源配色原样恢复；也能读
  `.npy/.edf`（那种读回来统一按手动显示）；
- **[导出通用掩膜…]**：另存 `.npy/.edf`，给 pyFAI-drawmask 等外部工具用，
  只有 bool 数组、没有来源信息。

导出配方/通用掩膜都**不会自动生成** Mask 2D；要再点 [生成 Mask 2D]。
保存后重新生成同一 raw+mask：只更新文件栏显示标签（用配方文件名），
**不重算已有 1D 缓存**。

## 7. 导出

- **导出 1D**：文件头会写 Mask 溯源，例如
  `# mask: sha 1a2b3c4d, 6561 px`；CSV 每列明细也带。
- **导出 Mask 2D 数据**：右键「Mask 后的 2D」→
  **[导出 Mask 2D 数据（.npz：image + mask）…]**。产物自包含：

```python
import numpy as np
z = np.load("xxx_mask2d.npz")
image = z["image"]   # 原始像素（float）
mask  = z["mask"]    # bool；True = 被遮掉
meta  = z["meta"]    # JSON：原始图路径、mask 哈希、像素数、标签
```

坏点仍是 mask，**不填 0/NaN**；换机器、没有原始图也能用。

## 8. 注意事项

- Mask 2D 产物在**缓存目录**里（`<缓存>/masked2d/`）；[删除所有缓存]
  会连它一起清掉。
- 右键删除 Mask 2D（单条/整组）会**连带清掉它名下的 1D/处理产物缓存**；
  原始图与 mask 文件不动。
- mask 形状必须与图像一致；换成不同尺寸/几何的图会报尺寸不一致，
  需要对那张图重新应用/清除 mask。
- 空 mask 不会生成产物（避免一条“什么都没遮”的假数据）。
- mask 是**像素级**的，不保存“圆/多边形”这类形状定义；跨软件复用时
  用导出的通用掩膜或 Mask 2D 数据。

## 常见问题

**Q：mask 后预览曲线几乎没变？**
A：如果遮的是 beamstop/束心附近，它在 1–8° 积分里贡献很小。把矩形画到
范围内的坏点团上，再点 [预览效果] 看对比；确认合理后再 [生成 Mask 2D]。

**Q：为什么不能等 1D 出来再扣？**
A：方位角积分把每个 2θ 环带里的像素做平均；坏点/beamstop 一旦进入平均，
1D 曲线已经错了。Mask 必须在积分前生效。

**Q：为什么标定页没有用 mask？**
A：标定是找环/定几何，不是积分；mask 只保护 2D→1D 的强度平均。标定
仍用原图。

**Q：能给整批 81 帧一次生成吗？**
A：可以。先在代表性图上画好 mask，把生成范围切到「勾选的 N 个文件」，
在文件栏勾选整批原始图，再点 [生成 Mask 2D]。同一张 mask 会生成到
每张图上，1D 再各自计算。
