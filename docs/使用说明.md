# XRD Toolkit 使用说明（v0.1.2 试用版）

把二维 XRD 衍射图像（`.tif` / `.edf` / `.cbf`）按标定好的几何积分，导出
可直接用于 Excel、Origin 或论文的 1D 曲线。

> 下面按顺序跟着做即可，每一步末尾的**确认**做到了再往下走。
> 软件更新后如与本文不符，以界面为准。

## 第 1 步：安装并打开软件

| 你的电脑 | 下载 |
|---|---|
| Windows 10 / 11 | [`XRD-Toolkit-windows.zip`](https://github.com/xyyzzc3/xrd_toolkit/releases/latest/download/XRD-Toolkit-windows.zip) |
| Mac（苹果芯片：M1/M2/M3/M4…） | [`XRD-Toolkit-macos-apple-silicon.zip`](https://github.com/xyyzzc3/xrd_toolkit/releases/latest/download/XRD-Toolkit-macos-apple-silicon.zip) |
| Mac（Intel 处理器） | [`XRD-Toolkit-macos-intel.zip`](https://github.com/xyyzzc3/xrd_toolkit/releases/latest/download/XRD-Toolkit-macos-intel.zip) |

（链接指向 GitHub 的**最新发布**；打不开时直接在浏览器里访问
`github.com/xyyzzc3/xrd_toolkit/releases` 手动选。）

如不确定 Mac 的芯片类型：点左上角苹果菜单 →「关于本机」，看「芯片」一行。

**Windows**：解压 zip → 进入 `XRD Toolkit` 文件夹 → 双击 `XRD Toolkit.exe`
→ 首次出现蓝色"Windows 已保护你的电脑"提示时点 **更多信息 → 仍要运行**。
（若没有"更多信息"按钮：右键 `XRD Toolkit.exe` → 属性 → 勾选「解除锁定」→
确定 → 再运行。）

**Mac**：解压 → 得到 `XRD Toolkit.app` → **第一次需右键点它 → 选「打开」**
→ 弹窗里再点一次「打开」。此后双击即可。

> 第一次启动会多花十几秒（系统安全检查 + 首次建立字体缓存）。
> 软件未做系统签名，被系统拦截一次属于预期现象。

**确认**：看到主窗口——左边「文件」区、中央绘图区、右边参数面板。

![界面总览](../showcase/gui/gui_main.png)

## 第 2 步：出第一张 1D 图

1. 左上「文件」区点 `[打开…]` → 选「文件」或「文件夹」，导入衍射图像
   （可一次多选，也可直接选整个文件夹；菜单底部的「最近打开」能快速再开
   上次用过的文件或文件夹）。
   **确认**：文件列表里出现你的文件名。
   提示：**双击一个原始条目 = 打开它本身的 2D 图**（要 1D / 剖面 / 瀑布
   就点顶部对应的按钮）。
2. 勾选一个文件：点它这一行最左边的对号框（整组一起勾就点组那一行）。
   **确认**：对号框打上勾。
3. 点顶部 `[1D]`，再点页面底部的 `[出图（已勾选 1 项）]`。
   **确认**：中央画出一张曲线图，窗口标题形如 `1D_文件名`；日志出现
   「积分完成」。

> 曲线横轴是 2θ、纵轴是强度。2θ 范围与点数在右侧参数面板顶部那一行；
> 改了这两项要点 `[重算这张图]` 才生效。其余显示参数改完立刻生效。

## 第 3 步：导出这条曲线

1. 文件区点 `[导出数据]`，选一个输出目录。
   **确认**：得到两列文本文件 `xxx_1D.txt`，Excel、Origin 都能直接打开。

（多条一起导出、文件命名规则等细节见第 7 步。）

## 第 4 步：几何配置——积分准不准由它决定

软件内置本实验室第 1 批（lmfp1）的标定，直接能用。**换新批次、或动过
探测器**时按下表重新标定（只做一次，之后这一批的所有图像都能用）：

1. 拍一张 LaB₆ 标样图，按第 2 步的方法导入并勾选。
2. 点顶部 `[校准]`。
   **确认**：中央出现标样图，图上有青色理论环（= 当前配置的几何）。
3. 点 `[定位束心并精修]`，等日志出现「完成」。
   **确认**：数据区「环位偏差」小于 1 px（越小越好）、「完整环」为 16/16。
4. 点 `[保存为配置]`，在「条目名称」里起个名字（如 `batch2_lab6`）。
   **确认**：参数面板顶部的「几何配置」一行能选到新名字。

别人标定好的 `.poni` 文件：在参数面板 `[加载几何…]` 直接导入，跳过 1–4。

![校准工作台](../showcase/gui/gui_calib.png)

> 拟合残差为 0 不代表标定正确——所以这一页特意给出「环位偏差」与
> 「完整环数」两个"残差量不到"的指标；判好坏看它俩。

## 第 5 步：改善曲线——背景扣除、平滑与裁剪

处理的对象是「编辑对象」那张图：先在文件栏**双击一条「1D 产物」**选定它
（参数面板顶部会显示它的名字）。

1. 点顶部 `[处理]`。
2. **背景扣除**（最常用的一步）：模式选「自动基线（推荐）」，窗口保持 0.2°。
   **确认**：图上出现扣过背景的曲线。
   - 想做"最干净"的背景：选「空扫相减」（需要拍过空扫图并选进来）；
   - 宽鼓包样品：选「手动锚点」→ `[拾取锚点]` → 在图上点几处"只有背景"
     的位置（锚点之外由基线形状推出，看「覆盖」范围是不是够了）。
   - 负值会保留（噪声本底是真实的，截成 0 会把平均值抬高约 1σ）——这是
     有意设计。
3. **平滑**：默认 Savitzky–Golay、窗口 0.10°，对峰形保留最好；窗口别取到
   峰宽量级，否则会削峰。
4. **裁剪**：把强度极高、压低其余信号的强峰挖空——例如填 2.5–2.6° →
   `[添加]`。可以加好几段。
5. 整批套用：在文件栏勾选要处理的文件 → 点 `[存成产物（已勾选 N 项）]`。
   **确认**：文件栏出现「处理产物」分组，之后的对比、热图、导出都能直接用它。

![背景扣除：原始 / 基线 / 结果三线](../showcase/gui/gui_background.png)

## 第 6 步：批量、对比与热图

- **批量出图**：`[打开…]` 选文件夹 → `[全选（原始数据）]` → `[1D]` →
  `[出图（已勾选 N 项）]`。超过 24 项时软件只计算、不弹面板（防爆图）——
  结果都在文件栏「1D 产物」组里，双击看单张、右键整组打开。
- **对比**：勾选 2 条以上曲线（原始数据 / 1D 产物 / 处理产物都行）→
  `[对比]`，多条叠在一张图里。曲线名默认不显示（鼠标悬停看读数）；
  想要图例就在「对比」页勾 `[显示数据名]`。
- **热图**：`[热图]` 把整批拼成一张 2θ × 样品的强度图；点某一行 = 在对比
  面板里显示/隐藏该样品曲线。

![批量热图](../showcase/gui/gui_heatmap.png)

## 第 7 步：文件都在哪、怎么管理

- 输出位置都在 **`个人文件夹/XRD_Toolkit`**（Windows 是 `文档\XRD_Toolkit`），
  导出对话框显示的也是这个路径；
- 单个文件导出 = 一个 `txt`；多条一起导出 = 新建文件夹
  `导出_日期_时间_内容标签/`，内含每条一个 `txt/` 和一张 `全部数据.csv`
  （每列一条曲线，Excel 里表头紧挨着数据）；
- **同名不会被覆盖**：重复导出自动加序号（`_2`、`_3`），日志里写明；
- 其中的 `_stage` 子文件夹是缓存，**可以删**（删后下次重算、稍慢）；
  导出的数据和 `config_user.json`（你的标定配置）**请勿删**。

## 常见问题

| 现象 | 怎么办 |
|---|---|
| 双击没反应 / 提示"已损坏" | Mac：右键 → 打开（第 1 步）；Windows：更多信息 → 仍要运行 |
| 第一次打开很慢 | 正常，正在建立字体缓存 |
| 软件里什么都没有 | 先 `[打开…]` 导入图像，再勾选文件，再出图（第 2 步） |
| 点 `[出图]` 没反应 | 检查文件行最左边的对号框是否勾上——只画勾选的条目 |
| 曲线噪声大 / 背景高 | `[处理]` 页做背景扣除与平滑（第 5 步） |
| 峰位整体偏、环不圆 | 几何配置不对——重新校准（第 4 步） |
| 想清理缓存释放空间 | 文件栏右键 →「删除所有缓存…」（导出和配置不受影响） |
| 程序出错 | 把 `个人文件夹/XRD_Toolkit/crash-watch.txt` 与界面截图发给开发者 |
