# XRD Toolkit 使用说明（v0.1.2 试用版）

本软件把二维 XRD 衍射图像转换为标准 1D 谱图：读取仪器导出的
`.tif` / `.edf` / `.cbf` 图像，按标定好的几何积分，导出可直接用于 Excel、
Origin 或论文的曲线。

> 软件更新后如与描述不符，以界面为准。

## 1. 安装与第一次打开

| 你的电脑 | 下载 |
|---|---|
| Windows 10 / 11 | `XRD-Toolkit-windows.zip` |
| Mac（苹果芯片：M1/M2/M3/M4…） | `XRD-Toolkit-macos-apple-silicon.zip` |
| Mac（Intel 处理器） | `XRD-Toolkit-macos-intel.zip` |

如不确定 Mac 的芯片类型：点左上角苹果菜单 →「关于本机」，看「芯片」一行——
写着「Apple M…」选苹果芯片，写着「Intel」选 Intel。

**Windows**：解压 zip → 进入 `XRD Toolkit` 文件夹 → 双击 `XRD Toolkit.exe`
→ 首次出现蓝色"Windows 已保护你的电脑"提示时点 **更多信息 → 仍要运行**。
（若窗口中没有"更多信息"按钮：右键 `XRD Toolkit.exe` → 属性 → 勾选底部的
「解除锁定」→ 确定 → 再运行。）

**Mac**：解压 → 得到 `XRD Toolkit.app` → **第一次需右键点它 → 选「打开」**
→ 弹窗里再点一次「打开」。此后双击即可。

> 第一次启动会多花十几秒（系统安全检查 + 首次建立字体缓存），之后正常。
> 软件未做系统签名，因此系统会拦截一次，这属于预期现象。

## 2. 三步上手

![界面总览](../showcase/gui/gui_main.png)

1. **打开**：左上「文件」区点 `[打开…]`，选择仪器导出的图像（可多选，也可
   直接选整个文件夹）。
2. **出图**：勾选文件（点条目行的对号）→ 顶部 `[1D]` → `[出图（勾选文件）]`。
   2θ 范围与点数保持默认即可；如需修改，在右侧参数面板顶部那一行。
3. **导出**：文件区 `[导出数据]` → 选择输出目录 → 得到两列 txt（对部分软件
   也可用 `.chi` 后缀）。

## 3. 几何配置（最关键的一步）

积分结果是否正确，取决于探测器几何是否标定准确。当前几何配置显示在参数面板
顶部那一行（如 `lmfp1_lab6`）。

- 软件内置本实验室第 1 批（lmfp1）的标定，可直接使用；
- **更换新批次或调整过探测器后**，需要重新标定：拍一张 LaB₆ 标样图 → 顶部
  `[校准]` 页 → 按页内顺序操作（自动定位 → 查看指标）→ 确认无误后
  `[保存为配置]`，此后所有图像都可以选用它；
- 他人标定好的 `.poni` 文件：可在参数面板 `[加载几何…]` 直接导入。

![校准工作台](../showcase/gui/gui_calib.png)

指标解读：**环位偏差中位**越小越好（< 1 px 已经很理想）；「完整环数」
越多越好（说明束心没有偏移）。拟合残差为 0 不代表标定正确——本页特意同时
给出这两类"残差量不到"的指标。

## 4. 改善曲线质量：背景扣除、平滑与裁剪

`[处理]` 页提供三项，修改后立即在图上预览：

- **背景扣除**：三种模式——空扫相减（效果最干净，但需要实际拍过空扫图）、
  自动基线（一键完成，最常用）、手动锚点（在图上点选几处"只有背景"的位置，
  适合宽鼓包样品）。**负值会保留**（噪声本底是真实的，截成 0 会把平均值
  抬高约 1σ）——这是有意设计。
- **平滑**：滑动平均或 Savitzky–Golay（后者对峰形保留更好）。窗口宽度应
  远小于峰宽。
- **裁剪**：把某个 2θ 区间挖空（例如避开一个强度极高、压低其余信号的强峰）。

![背景扣除：原始 / 基线 / 结果三线](../showcase/gui/gui_background.png)

参数调好后可对整批生效：勾选要处理的文件 → `[批量处理]`。每张图的结果会
出现在文件栏的「处理产物」分组里，可以直接用于对比、热图和导出。

## 5. 批量、对比与热图

- **批量**：`[打开…]` 选文件夹 → `[全选]` → `[1D]`。超过 24 张时软件只计算
  不绘图（控制内存占用），结果都进文件栏「1D 产物」分组，双击查看单张。
- **对比**：勾选整组 → `[对比]` → 多条曲线叠在一张图里（图例超过 12 条时
  自动省略，辨认曲线以鼠标悬停读数为准）。
- **热图**：`[热图]` 把整批数据拼成一张 2θ × 样品的强度图，点击某一行可以
  在对比图中显示/隐藏该曲线。

![批量热图](../showcase/gui/gui_heatmap.png)

## 6. 导出与文件位置

- 导出的曲线是**两列文本**（2θ(deg)，强度），几乎所有软件都能直接打开；
- 多条一起导出会新建一个文件夹 `导出_日期_时间_内容标签/`，里面有每条曲线
  一个文件的 `txt/` 子目录和一张 `全部数据.csv`（每列一条曲线，说明列在最
  上方，Excel 里表头紧挨着数据）；
- **同名文件不会被覆盖**：重复导出会自动加序号（`_2`、`_3`），日志里写明；
- **文件位置**：所有文件都在 `个人文件夹/XRD_Toolkit`
  （Windows 是 `文档\XRD_Toolkit`），导出对话框里显示的也是这个路径。
  其中的 `_stage` 子文件夹是缓存，**可以删除**（删除后下次重算，速度稍慢）；
  导出的数据和 `config_user.json`（你的标定配置）**请勿删除**。

## 7. 常见问题

| 现象 | 怎么办 |
|---|---|
| 双击没反应 / 提示"已损坏" | Mac：右键 → 打开（见第 1 节）；Windows：更多信息 → 仍要运行 |
| 第一次打开很慢 | 正常，正在建立字体缓存；之后恢复正常 |
| 软件里什么都没有 | 先 `[打开…]` 导入你的 `.tif` 图像，再勾选文件，再出图 |
| 曲线噪声大 / 背景高 | 到 `[处理]` 页做平滑、背景扣除（见第 4 节） |
| 峰位整体偏、环不圆 | 几何配置不正确——请重新校准（第 3 节） |
| 想清理缓存释放空间 | 文件栏右键 →「删除所有缓存…」（导出和配置不受影响） |
| 程序出错 | 请把 `个人文件夹/XRD_Toolkit/crash-watch.txt` 与界面截图提供给开发者 |

- `crash-watch.txt` 是崩溃现场记录，**可能包含本机文件路径**；对外分享前
