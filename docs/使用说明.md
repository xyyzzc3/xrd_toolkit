# XRD Toolkit 使用说明（0.1 试用版）

一句话：把二维 XRD 衍射图变成标准 1D 谱图的桌面软件——读取仪器导出的
`.tif` / `.edf` / `.cbf` 图像，按标定好的几何积分，导出可以进 Excel、
Origin、论文的曲线。

> 本文对应 0.1.0 试用版。软件更新后如与描述不符，以界面为准。

## 1. 安装与第一次打开

| 你的电脑 | 下载 |
|---|---|
| Windows 10 / 11 | `XRD-Toolkit-windows.zip` |
| Mac（苹果芯片：M1/M2/M3/M4…） | `XRD-Toolkit-macos-apple-silicon.zip` |
| Mac（Intel 处理器） | `XRD-Toolkit-macos-intel.zip` |

分不清 Mac 芯片看「关于本机」："芯片"写 Apple M\*\* 选苹果芯片，写 Intel 选 Intel。

**Windows**：解压 zip → 进入 `XRD Toolkit` 文件夹 → 双击 `XRD Toolkit.exe`
→ 首次出现蓝色"Windows 已保护你的电脑"时点 **更多信息 → 仍要运行**。

**Mac**：解压 → 得到 `XRD Toolkit.app` → **第一次要右键点它 → 选「打开」**
→ 弹窗里再点一次「打开」。以后双击即可。

> 第一次启动会多花十几秒（系统安全检查 + 首次建字体缓存），之后正常。
> 软件没有花钱做系统签名，所以系统会拦一次——这是我们主动说明的正常现象。

## 2. 三步出结果

![界面总览](../showcase/gui/gui_main.png)

1. **打开**：左上「文件」区点 `[打开…]`，选仪器导出的图像（可多选，也可
   直接选整个文件夹）。
2. **出图**：勾上文件（点条目行的对号）→ 顶部 `[1D]` → `[出图（勾选文件）]`。
   2θ 范围与点数默认即可；要改在右侧参数面板顶部那行。
3. **导出**：文件区 `[导出数据]` → 选输出目录 → 得到两列 txt（或用
   `.chi` 后缀给某些软件）。

## 3. 几何配置（最重要的一件事）

积分结果对不对，取决于"探测器几何"标得准不准。几何配置就在参数面板顶部
那行显示（如 `lmfp1_lab6`）。

- 软件内置了本实验室第 1 批（lmfp1）的标定，直接可用；
- **换了新批次 / 动了探测器**，就要标一次：拍一张 LaB₆ 标样图 → 顶部
  `[校准]` 页 → 按页内顺序（自动定位 → 看指标 → 精修）→ 满意后
  `[保存为配置]`，之后所有图都能选它；
- 别人标好的 `.poni` 文件：参数面板 `[加载几何…]` 直接导入。

![校准工作台](../showcase/gui/gui_calib.png)

指标怎么看：**环位偏差中位**越小越好（< 1 px 就很好了）；"完整环数"
越多越好（说明束心没跑偏）。拟合残差是 0 不代表标对了——本页特意同时
给出这两类"残差量不到"的指标。

## 4. 让曲线更好用：背景扣除 / 平滑 / 裁剪

`[处理]` 页三项，都是改一下立刻在图上看到：

- **背景扣除**：三种模式——空扫相减（最干净，但要真拍过空扫图）、
  自动基线（一键，最常用）、手动锚点（在图上点几处"只有背景"的位置，
  适合宽鼓包样品）。**负值会保留**（噪声地板是真的，截成 0 会把平均值
  抬高约 1σ）——这是有意的。
- **平滑**：滑动平均或 Savitzky–Golay（后者保峰更好）。窗口要远小于峰宽。
- **裁剪**：把某个 2θ 区间挖空（比如躲开一个压扁一切的巨峰）。

![背景扣除：原始 / 基线 / 结果三线](../showcase/gui/gui_background.png)

调好后对整批生效：勾上要处理的文件 → `[批量处理]`。每张图的结果会出现在
文件栏的「处理产物」分组里，可以被对比、热图和导出直接使用。

## 5. 批量、对比与热图

- **批量**：`[打开…]` 选文件夹 → `[全选]` → `[1D]`。超过 24 张时软件只算
  不画（防爆内存），结果都进文件栏「1D 产物」，双击看一张。
- **对比**：勾上整组 → `[对比]` → 多条曲线叠一张图（图例超过 12 条自动省略，
  认曲线看鼠标悬停读数）。
- **热图**：`[热图]` 把整批拼成一张 2θ × 样品 的强度图，点某一行可以在
  对比图里显示/隐藏那条曲线。

![批量热图](../showcase/gui/gui_heatmap.png)

## 6. 导出与"我的文件在哪"

- 导出的曲线是**两列文本**（2θ(deg)，强度），任何软件都打得开；
- 多条一起导会建一个文件夹 `导出_日期_时间_内容标签/`，里面有每条一个的
  `txt/` 和一张 `全部数据.csv`（每列一条曲线，说明列在最上面，Excel 里
  表头紧挨着数据）；
- **同名文件不会被覆盖**：重复导出会自动加序号（`_2`、`_3`），日志里写明；
- **所有文件都在**：`个人文件夹/XRD_Toolkit`
  （Windows 是 `文档\XRD_Toolkit`），导出弹窗里显示的也是这个路径。
  里面的 `_stage` 子文件夹是缓存，**可以删**（删了下次重算，稍慢）；
  导出的数据和 `config_user.json`（你的标定）**别删**。

## 7. 常见问题

| 现象 | 怎么办 |
|---|---|
| 双击没反应 / 提示"已损坏" | Mac：右键 → 打开（见第 1 节）；Windows：更多信息 → 仍要运行 |
| 第一次打开很慢 | 正常，建字体缓存；之后快 |
| 软件里什么都没有 | 先 `[打开…]` 导入你的 `.tif`，再勾选、再出图 |
| 曲线毛刺多 / 背景高 | `[处理]` 页：平滑、背景扣除（见第 4 节） |
| 峰位整体偏、环不圆 | 几何配置不对——重新校准（第 3 节） |
| 想清缓存省空间 | 文件栏右键 →「删除所有缓存…」（导出和配置不受影响） |
| 出错了 | 把 `个人文件夹/XRD_Toolkit/crash-watch.txt` + 界面截图 发我 |

## 8. 数据、隐私与许可

- **所有计算都在你的电脑上完成**：软件不联网、不上传任何数据、没有
  使用统计（遥测）。实验数据不出本机。
- `crash-watch.txt` 是崩溃现场记录，**可能包含本机文件路径**；发给别人前
  可以先自己打开看一眼。
- 免责：本软件是科研工具，结果取决于几何标定与参数选择，**发表或交付前
  请人工复核**关键数值。
- 许可：本软件 MIT 许可；随附的第三方组件（Qt/PySide6、pyFAI、NumPy、
  SciPy、Matplotlib 等）各自的许可全文见随包文件
  `THIRD_PARTY_NOTICES.txt`。
