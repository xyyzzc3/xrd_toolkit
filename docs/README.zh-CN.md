# XRD Toolkit

XRD 衍射图像处理工具箱：读取 `.tif` / `.edf` / `.cbf` 二维衍射数据，用 LaB₆ 标样做几何校准，把二维衍射图积分成标准 1D 粉末谱——四个命令行脚本，外加一个跑在同一个引擎上的 PySide6 桌面界面。本项目是香港城市大学 *PHY6528 Advanced Research in Applied Physics* 的课题工作。

English: [README.md](../README.md) · 详细说明（校准指标、扣背景、批量与产物、工程细节）：[NOTES.zh-CN.md](NOTES.zh-CN.md)

## 能做什么

- **2D → 1D 积分**——0°–360° 完整方位角积分，输出标准两列 txt（2θ(deg), intensity），供寻峰、拟合、PDF 分析使用。
- **LaB₆ 标样几何校准**——pyFAI `GeometryRefinement` 对 NIST SRM 660（a = 4.156 Å）标定，初值用 FFT 互相关自动定位直射束位置（精度 < 1 px）。实测：距离精修到 1595.80 mm（条目 `lmfp1_lab6`）。每次校准还报**三个拟合残差量不到的引擎指标**：环位偏差中位、16 条环里完整跑出来的条数、逐环反推的晶格常数离散度——实测过残差 0.0000° 而环位偏 10 px 的情况。
- **自动 2θ 区间**——`--range auto`（默认）：下界按材料专属标准取，上界按"数据失效点"自动判定，判据是**相对弧覆盖率**（环落在探测器内的方位比例跌破自身峰值的 50%，居中摆法约 7.9°）而不是一个写死的阈值，因此束心摆在哪儿都适用。
- **扇形积分 + 瀑布图**——默认 36 扇区各自积分，原强度堆叠瀑布图一眼看出择优取向 / 大晶粒，并把探测器切环的几何画出来。所有行共用一个行高（全场峰值 × 0.7，**不**按各扇区自己的峰值缩放，所以峰更高就真的是更强的扇区）；界面版还会逐扇区跑处理链——把压扁其他峰的巨峰裁掉，弱扇区就看得清了。
- **偏置束心（部分环）**——束心打在探测器边缘或角落的数据全程支持；pyFAI 分箱不可靠时自动切到自研的 numpy 极坐标积分（合成环上验证过）。
- **背景扣除**——空扫相减（可填曝光/束流归一化系数）、自动基线（滑动窗 + 窗口内直线拟合：陡降背景上低角不再扣过头）、手动锚点（在图上点只有背景的位置，锚点之间默认走保单调平滑，过点、不过冲），三种都实时预览：原始曲线（虚线）、基线（点线）叠在扣除结果上；**调参时纵轴不跟着动**（按未扣的原始曲线定框），只有曲线在框里往下走。锚点在**自动基线**模式下同样生效（同一批数据里背景的形状是共同的、绝对强度不是）：**锚点定电平、自动基线定形状**——你点过的那段严格过点，没点到的角度就沿着自动基线那条会弯的曲线平移过去，不再从两个几乎重合的锚点拉一条直线出去（那样会把整批曲线抬歪几千 counts）。产物组名里记着**锚点覆盖的角度范围**，"哪些是点过的、哪些是推出来的"一眼可查。负值默认保留（噪声地板是真的，截到 0 会把均值抬高约 1σ）。SNIP 也实现并实测过，因过度扣除 43%–98% 而不放进界面。
- **批量与分阶段产物**——文件夹一键导入、整批积分（**超过 24 张就一张都不画**：全部后台算完落盘、结果列进文件栏，双击**产物**看一张、右键整组打开（双击**原始数据**不出图——原始数据能出四种图，交给视图按钮）），一张图就能对比或看热图。1D 曲线与扣背景曲线按阶段缓存（`outputs/_stage/`，键 = 文件指纹 + 几何 + 设置，跨会话复用），并在文件栏里显示成**分组**：扣完背景的那一批，两下点击就进对比图，不用重积分。
- **桌面界面**——MDI 图面板（可弹出、可平铺）、实时参数面板、悬停读数、框选放大、单条曲线自定义配色、PNG/TIF 导出：

  ```bash
  python -m xrd_toolkit.gui
  ```

## 安装

```bash
conda env create -f environment.yml    # 只需一次
conda activate XRD_Toolkit_Environment
pip install -e .                       # numpy / scipy / matplotlib / fabio / pyFAI 一并装上
```

> 示例数据没有上传到仓库，请把 `--file` 换成你自己的衍射数据路径。

```bash
# 校准 + 积分一张图（跑完会打印一段可直接粘进 config.py 的配置条目）
python scripts/calibrate_integrate.py --file data/xxx.tif --wavelength 0.1223 --pixel 200 --dist0 1600
# 用已标定的几何做全角度积分；扇形积分 + 瀑布图
python scripts/integrate_pattern.py  --file data/xxx.tif
python scripts/sector_waterfall.py   --file data/xxx.tif --n-sectors 36
```

典型流程：`view_diffraction`（看图）→ `calibrate_integrate`（几何校准）→ `integrate_pattern`（1D 标准谱）→ `sector_waterfall`（方位均匀性）。输出都在 `outputs/{数据名}/` 下——默认就是项目根的 `outputs/`，从哪个目录启动都落同一处（GUI 导出同理）。不带 `--file` 时每个脚本会弹出 `data/` 里的文件菜单（`1,2` 多选、`all` 全选）；三个积分脚本用 `--config 条目名` 选几何（默认 `lmfp1_lab6`）。**完整参数说明见 [NOTES.zh-CN.md](NOTES.zh-CN.md#命令行参数)。**

| 脚本 | 作用 |
|---|---|
| `scripts/view_diffraction.py` | 衍射图查看器（对数色标、线剖面、标定过的束心标记） |
| `scripts/calibrate_integrate.py` | LaB₆ 几何校准（pyFAI）+ 方位角积分（2D→1D） |
| `scripts/integrate_pattern.py` | 全角度积分：2D 图 → 标准 1D 谱 |
| `scripts/sector_waterfall.py` | 扇形积分（36 扇区）+ 瀑布图 + 方位均匀性统计 |
| `scripts/check_env.py` | 环境自检——"跑不起来"时先跑它 |
| `scripts/check_gui.py` | 界面链路探针——真数据 + 真画布事件把界面走一遍 |
| `scripts/show_gui.py` | 真窗口看一眼——真数据走三步，窗口留给你自己点 |
| `scripts/run_tests.py` | 带看门狗的全量测试 |
| `scripts/stress_panels.py` | 面板压力探针——两处 offscreen 死锁的回归检查 |

## 界面

- **工具栏五个入口**——`[校准] [1D] [扣背景] [对比] │ [绘图]`：点一个 = 右侧参数面板翻到那一页，只放本阶段的东西（含本页的产出按钮）。**开界面时上面一个都不选、右侧参数栏是收起的**，选到谁才露出谁。参数面板顶部固定三行：编辑对象、当前几何配置、**数据参数（2θ 积分范围 + 输出点数）**——范围在四个分析页都能改，不用回 1D 页（校准页把它收起来：校准不读 2θ 区间）。
- **处理页**——三项可选项，都是"改参数立刻看到"：[背景扣除]（空扫 / 自动基线 / 手动锚点）、
  [平滑]（滑动平均 / Savitzky–Golay 两种，窗口按 2θ 给；同一窗口下 SG 保峰好得多，实测削 82% vs 91%）、[裁剪]（把某段 2θ 挖掉，让被巨峰压扁的其余部分看得清）。
  一张图调好后点 [批量处理]，整批各生成一份处理产物（文件栏里成为「处理产物 …」分组），
  对比 / 热图 / 导出都读它。**配方可以存下来带走**：[存成配方…] 把当前这套——模式、窗口、锚点**位置**、
  平滑、裁剪——存成命名条目（`outputs/recipes.json`），[套用] 可以把它用到任何一张图上；锚点的**强度**
  永远按目标图自己的曲线重取，所以同一套配方能用在第二批数据上，而绝对高度各图自负（落在某张图 2θ 范围外的
  锚点会被丢掉并报一行，不会静默钳到端点值）。
- **一键出图**——「绘图」页里的 [2D] [剖面] [1D] [瀑布] 把勾选的文件一次全部出图；[对比] 把多条曲线叠进同一面板（三种归一化，都是全场统一的比例——刻意没有「各自最强峰」那种逐条缩放的模式；**超过 12 条曲线不再画图例**——那 81 行名字比数据还占地方，认曲线改看状态栏悬停读数）；[热图] 把整批拼成一张 2θ×样品 图（[对比] 与 [热图] 都是**单槽面板**：按下按钮 = 按**当前**勾选重建那一张，取消勾选的东西就真的不在了，也不会有旧面板留着上一次的勾选），行名自动缩成号段并按面板高度抽稀，点热图某一行 = 在对比图里隐藏/显示该条曲线。
- **文件栏**——一棵树：顶上是原始数据，往下是各阶段产物分组（「1D 产物」= 当前设置算好的；「处理产物 …」= 每次 [批量处理] 一组，组名带时间与参数）。**勾组 = 组里整组勾上**，整组勾上去 [对比]/[热图] 就是两下点击的事；**双击产物**条目看这一张（原始条目双击不出图——原始数据能出四种图，交给视图按钮）；产物分组右键能整组打开，**原始数据组也能**，另外右键文件栏本身还有一条「打开勾选的 N 张 1D 图」——它**没有 24 张上限**，只弹一次确认。导入默认一个都不勾：**一个 [全选/全不选] 切换按钮**（标签跟着状态变）或 [按条件选…]（区间·间隔·名字筛选，带实时预览）。**勾了什么就画什么，而且写在按钮上**：出图按钮直接写着「出图（勾选 162 个）」，上方一行摘要说明构成（"原始 81 ｜ 1D 产物 81"），并在**同一文件的原始条目和它自己的 1D 产物都勾着**时提醒"同一条曲线会画两遍"。**文件栏就是缓存的镜子**：「1D 产物」组按磁盘扫出来建，改 2θ 范围不会让它消失——按别的设置算的产物也列着、并在名字里标出范围（「· 1D（2θ 1–8°）」）；旧背景算法算的那批标「旧算法，不可信」而不是藏起来；除了你自己删，文件栏里不会少东西。文件栏也不再乱跳：导入不会滚到最新那个文件、重建保留滚动/收起/勾选、取消勾选也不再被拽回顶端。打开收成一个 [打开…]（菜单里选文件或文件夹）。**原始条目永远画原始曲线**：处理过的文件记着它的**配方**（处理页那行「本图配方：…」），但打开时**不自动套用**——要套按 [套用]，要看结果点文件栏「处理后」那一条；数据还在算的面板写着「正在计算…」，不是一块空白。
- **右键一个入口管全部**——**删除**：原始数据只从列表移除（硬盘上的文件永远不动），产物真删（单条或整组，连带台账）；**导出**：产物条目可直接导出 txt / chi（单条就一个文件）、分组还能带上全部数据总表，不必先去勾选；菜单最后一项是**删除所有缓存**（二次确认）。
- **实时参数面板**——每个面板的数据与显示参数集中一栏（提示气泡全覆盖，分组重置/应用，面板快照）；数据组的 2θ 范围直接约束积分本身，缩放/平移实时写回视图范围。
- **面板壳与手势**——每面板一行自绘标题栏（复位视图 / 放大镜 / 外观… / 保存图片…，外加弹出与关闭）；左键拖动平移、放大镜点亮后滚轮以光标为中心缩放 + 左键拖框放大、悬停时状态栏显示数据点读数、每条边都能拖；绘图区底部一角有 [横排][竖排][全部关闭]，一次关掉所有图面板。**Home 键**与标题栏那个 [复位视图] 等效，作用于鼠标最后停过的那张图——它是纯粹的看图动作：把画面还原成"生成这张图时"的视图，一个参数都不改（在数值框里打字不受影响，那儿的 Home 仍是"光标到行首"）。"最初的样子"**不会被缩放或点锚点改掉**：重画只是把缩放窗口再套一遍时，不再拿它当"家"，所以放大再点几次锚点，一按仍是全图。
- **校准工作台**——三列表（当前配置 + 对比位 A / B）压着自动与手动两套动作；每个结果按自己的名字累积，**你按按钮跑出来的结果一律成为当前配置**（青环立刻跟着动，图上标题写明"Cyan rings = current config: 哪条结果 · ring deviation 多少 px"；好了/差了多少写在日志里，从不悄悄替换）。这一页上 Δ 行与**结论**用的是同一个参照，而且**永远是「当前配置」**：Δ = 该列 − 当前配置（当前配置那一列自己写「基准」），结论把 A、B 两个候选分别对着它判，两边的名字和数字都写全（"A 比 当前配置 好 0.32 px（环位偏差 当前配置 0.73 px ｜ A 0.41 px）"）——这一页要决定的本来就是"要不要采纳它"。原先这里还有个「对比基准」下拉框（2026-09-30 删掉："直接把对比基准删了，直接出结论当前配置和 a、b 对比分别怎么样，随着用户选择 ab 当前进行变化"）：少一步选择，也不会再出现"基准列写着 A、结论在讲 B"这种要绕一下的表述——换掉 A/B 槽里钉的结果，Δ 行与结论立刻跟着变。参数面板顶部钉着三行全局控件：编辑对象、当前用哪条几何条目（任何一页都能换，悬停看像素尺寸 / 波长 / 距离，校准页的提示会补一句"校准跟的是本页的当前配置"；校准模式下同一行给出 [退出校准] 出口），以及**数据行**（2θ 范围 + 输出点数，五个分析页共用）。参数面板显示的**永远是"编辑对象"那张图的参数**；改了还没生效的（2θ 行要按 [重算这张图]、显示参数要按 [应用显示设置]）会在旁边点亮一个灰字 **「未应用」**，而且这份改动**按图记着**——切走再切回来，你填的值还在（用户 2026-09-30："参数页显示本图的参数……如果用户改了，添加一个灰字未应用来区分，切图再切回来保持"）。指标**抓不到什么**也写在 [详细说明](NOTES.zh-CN.md#校准) 里。
- **几何参数进出**——[保存几何…] 把当前配置写成 pyFAI 通用 `.poni` 文件，[加载几何…] 读回来存成命名条目（重启仍在，命令行 `--config` 同样可用）。

## 测试

```bash
python scripts/run_tests.py     # 617 条，带看门狗
```

合成图像单元测试（不需要真实数据，纯 unittest）：弧覆盖率失效判据（居中/边缘/角落/束心在图像外四种摆法）、几何失效点数值、偏置摆法的自研积分兜底、各背景估计器对已知合成背景的表征，以及界面的接线（实时预览、按文件记锚点、原始/基线辅助线）。

`scripts/stress_panels.py` 是两处 offscreen 死锁的回归探针（都已修：面板工具栏改自绘、后台任务改长驻工作线程）；`scripts/run_tests.py` 给套件带看门狗——万一卡住会打印所有线程的 Python 栈并以非 0 退出，不会静默挂到天荒地老。

## 路线图

- 1D 图谱上的寻峰与峰形拟合（背景扣除先落地——扣掉基线之后峰高与峰面积才有意义）
- 线形分析：Scherrer / Williamson–Hall 尺寸-应变
- 结构因子模拟
- 基本的 Rietveld 精修引擎
- 机器学习：物相识别聚类 + 峰形 CNN 分类

```
└── pyproject.toml              # 项目元信息与依赖
```
