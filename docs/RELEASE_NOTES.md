# XRD Toolkit v0.2.0 正式版

不用装 Python、不用配环境：下载 → 解压 → 双击。

> **0.2.0（本次）**：这一版把"分析"整条链路搬进了桌面界面。
>
> - **四个分析工作台**：Mask（遮罩 → 生成 Mask 2D）、物相筛选（相库 /
>   元素过滤 / 多相叠加 / CSV）、全谱精修（额外相 / 仪器基线 / 采纳为
>   图面板）、原位三相批量——全部与参数页、图面板共享同一套引擎。
> - **原位工作台四视图**：趋势 / 汇总 / 单帧拟合 / 模型无关；每帧
>   从上一帧种子和 CIF 端元**双起点**精修，取更优解，晶胞跳变后连续
>   2 帧一致会重锁种子；少数相（<50%）晶胞在图上淡色显示，不作为
>   结构证据。
> - **1D 页峰形拟合 + W-H + Scherrer**：高斯 / 洛伦兹 / 伪 Voigt / 分裂
>   Pearson VII 单峰拟合；峰表与拟合结果合并成标签页；**W-H 卡片常显**
>   （没峰时点 `[去寻峰]` 直达峰表），≥3 根峰自动算 Williamson–Hall
>   （D / ε / 峰数 / 警告），可保存 W-H 图；同一批勾选峰逐峰算 Scherrer
>   尺寸。W-H 的仪器宽度可直接用精修工作台存下的 **LaB₆ 基线**（按角度
>   逐峰扣），也可以退回常数近似。
> - **定量相分数（wt%）**：多相精修的参数表/报告、原位表与 CSV 新增
>   晶态相 wt%（Z·M·V 从 CIF 与精修晶胞来；非晶/未知相不参与分母）。
> - **七晶系峰位晶胞精修**：物相工作台新增 `[峰位精修晶胞]`（也可命令行
>   `scripts/refine_cell.py`），立方/四方/六方/三方/正交/单斜/三斜都能
>   精修，同时修 2θ 零位。
> - **Mask 工作台**：画笔 / 矩形 / 孤立坏点、`.mask.npz` 配方、按范围
>   生成「Mask 后的 2D」。
> - **打包变化**：pymatgen 现在是主依赖（精修 / 物相 / 原位要读 CIF），
>   压缩包约 **150 MB**、解压后约 **340 MB**；原位工作台需要你自己选一张
>   **LaB₆ 标样帧**来定仪器峰形（仓库样例不再随包）。
> - **已知边界**：原位 `f_rich` 仍是相对散射强度分数；wt% 只对拟合
>   模型里的晶态相，非晶/未知相不参与分母；两相共存区 <50% 的 minority
>   晶胞受多数相拉偏，图上报淡色、不引用；物相筛选只做峰位匹配，不从零
>   指标化；W-H 只能混合同一个相的峰，没有 LaB₆ 基线时用常数近似；
>   精修的仪器基线只在当前程序运行内有效；GSAS-II 对照仍是独立脚本。
>
> 这是 **v0.2.0 正式版**，已在本地打包版上完成测试。已在用旧版本的用户
> 直接下载覆盖安装即可，标定、缓存与配方均会保留。

## 安装与第一次打开

三个平台的应用均**未做系统签名**，所以第一次打开时系统会拦截一次——
这属于预期现象，按下面步骤操作一次即可，之后不再提示。

**Windows**
1. 把 `XRD-Toolkit-windows.zip` 解压到任意文件夹（建议解压到桌面或 D 盘）
2. 进入解压出来的 `XRD Toolkit` 文件夹，双击 **`XRD Toolkit.exe`**
3. 如果出现蓝色窗口"Windows 已保护你的电脑" → 点 **更多信息** → 点 **仍要运行**
   （若没有"更多信息"按钮：右键 `XRD Toolkit.exe` → 属性 → 勾选底部的
   「解除锁定」→ 确定 → 再运行）

**Mac（Intel 或苹果芯片都一样）**
1. 把 zip 解压，得到 **XRD Toolkit.app**（可以拖进"应用程序"文件夹）
2. **第一次请勿直接双击**——要 **右键点它（或按住 Control 点）→ 选「打开」**
3. 弹窗里再点一次 **打开**。此后即可正常双击

## 快速上手

1. **打开数据**：左上「文件」区 → [打开…] → 选中仪器导出的 `.tif` 图像
   （支持 `.tif/.tiff/.edf/.cbf`，可多选）
2. **确定几何**：处理本实验室第 1 批数据时，软件内置的标定（`lmfp1_lab6`）
   直接可用；新批次或动过探测器，用随批拍的 LaB₆ 标样图在 [校准] 页标定
   一次（[保存为配置] 存下来，整批通用）。
   **几何不对，积分出来的峰位整体就是偏的**——所以先做这一步。
3. **出图**：勾选文件 → 顶部 [1D] 入口 → [出图（已勾选 N 项）]
   —— 2θ 范围、点数保持默认即可；如需修改，在右侧参数面板中调整
4. **导出**：文件区 [导出数据] → 选择输出目录 → 导出 txt / 全部数据总表

（细则——处理、对比、热图、每种导出选项——都在随包《使用说明》里。）

**文件位置**
- 导出的数据：导出对话框中显示的目录（Windows 默认 `文档\XRD_Toolkit`，
  Mac 默认 `个人文件夹/XRD_Toolkit`），路径可在对话框中自行修改
- 计算过的曲线缓存：上述目录中的 `_stage` 子文件夹（可删，只是下次重算）

## 数据与隐私

- **所有计算都在你本机完成**：程序不联网、不上传数据、没有使用统计。
- `crash-watch.txt` 是崩溃现场记录，可能含本机路径；对外分享前请先自行查看。
- 科研工具免责：结果取决于几何标定与参数选择，**发表/交付前请人工复核**关键数值。
- 许可：本程序采用 MIT 许可；随附第三方组件（Qt/PySide6、pyFAI、NumPy、
  SciPy、Matplotlib 等）的许可全文在包内 `THIRD_PARTY_NOTICES.txt`，
  程序内 **帮助 → 关于 → 第三方许可** 也可打开。

## 已知限制

- 未做系统签名：Windows 首次"仍要运行"、Mac 首次"右键→打开"（见上）
- 暂无自动更新：新版本发布后重新下载覆盖安装即可（缓存与配置不会丢失）
- 系统要求：macOS 13 起 / Windows 10 起
- 界面中文、图内文字英文（图片可直接用于论文）；导出数据为英文表头
