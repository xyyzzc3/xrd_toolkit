# XRD Toolkit v0.2.1 正式版

不用装 Python、不用配环境：下载 → 解压 → 双击。

> **0.2.1（本次）**：这一版把原位工作台统一成**通用多相页面**，并把
> 方案、精修和报告里的最后一批体验问题收口。
>
> - **原位页默认就是通用相表**：打开即可 `[加 CIF…]` 加任意相，每行设
>   角色（样品相/参考相）、晶胞、强度（结构因子/Le Bail）、是否计入
>   分数、B/峰宽；`[细节…]` 可填 B、尺寸、应变、初始晶胞、晶胞范围、
>   跳变容差和颜色。`LMFP 三相` 只是内置方案，选中就**当场替换**相表、
>   策略、视图和仪器来源，不再需要另开「通用多相」窗口。
> - **方案可存可载**：`[存方案…]` 把相表 + 策略 + 视图 + 仪器来源存成
>   `.json`，`[载方案…]`/下拉一键换回；跑批中换方案会先暂停，不会卡死。
> - **原位页能调背景和仪器来源**：背景可选自动基线（窗口可调）、
>   Chebyshev 联解或不用背景；仪器可选已保存基线、LaB₆ 标样帧现拟合
>   或不固定。结果表默认紧凑列（表头 `f1 / wt1% / a1 / c1` + P1/P2
>   图例），右键「诊断列」才看 esd/计时全列。
> - **报告里的原位图按方案画**：通用方案的报告新增汇总图；有峰窗时
>   画峰窗跟踪图，不再套 LMFP 的 (200) 双峰；图例用相名/图内名。
> - **精修工作台整理**：结构参数/额外相改成可常开的非模态窗口，左侧
>   只留高频选项；结果补 GoF；处理产物给红色提示；进入/退出工作台不再
>   闪白、1D 图不再被放大；B 因子默认与说明改准。
> - **方案管理页八项都能手动选**：第二相 CIF、相库目录、原位帧目录、
>   原位掩膜、掩膜工程、两态样品元素、处理设置都可直接选并写进方案；
>   坞顶几何下拉保留，校准页支持 `[删除配置]`。
> - **物相与论文图**：内置 41 张精选相库；样品元素分「一定有/可能有」，
>   元素表漏 Mn 时相近相照样打分并标橙色；三工作台图内文字全英文，
>   保存图默认 PDF（矢量）并嵌入 TrueType 字体；校准/掩膜 2D 图白边
>   收窄，对比堆叠缩放后调行距不再错位。
> - **长任务进度**：原位帧进度、掩膜 2D 批量、报告按节、物相筛相三段
>   都有进度条；原位 81 帧仍可在几分钟内跑完（本机约 3.5 分钟）。
> - **已知边界**：原位 `f_rich` / `f_<相>` 是相对散射强度分数；wt% 只
>   对拟合模型里的晶态相，非晶/未知相不参与分母；两相共存区 <50% 的
>   少数相晶胞不可作为结构证据（图上报淡色）；通用页的峰窗目前只能
>   在方案 JSON 里配置（LMFP 预设自带 (200) 窗口）；趋势/汇总/报告图
>   固定看晶胞 a、c（完整 a/b/c 在 CSV 与单帧报告里）；原位批量暂不
>   精修仪器峰形、原子坐标/占位或多主相；GSAS-II 对照仍是独立脚本。
>
> 这是 **v0.2.1 正式版**，已在本地打包版上完成测试。已在用旧版本的
> 用户直接下载覆盖安装即可，标定、缓存与配方均会保留。

## 安装与第一次打开

三个平台的应用均**未做系统签名**，所以第一次打开时系统会拦截一次——
这属于预期现象，按下面步骤操作一次即可，之后不再提示。

**Windows**
1. 把 `XRD-Toolkit-windows.zip` 解压到任意文件夹（建议解压到桌面或 D 盘）
2. 进入解压出来的 `XRD Toolkit` 文件夹，双击 **`XRD Toolkit.exe`**
3. 如果出现蓝色窗口"Windows 已保护你的电脑" → 点 **更多信息** → 点 **仍要运行**
   （若没有"更多信息"按钮：右键 `XRD Toolkit.exe` → 属性 → 勾选底部的
   「解除锁定」→ 确定 → 再运行）

**Mac（Intel 或苹果芯片都一样）**
1. 把 zip 解压，得到 **XRD Toolkit.app**（可以拖进"应用程序"文件夹）
2. **第一次请勿直接双击**——要 **右键点它（或按住 Control 点）→ 选「打开」**
3. 弹窗里再点一次 **打开**。此后即可正常双击

## 快速上手

1. **打开数据**：左上「文件」区 → [打开…] → 选中仪器导出的 `.tif` 图像
   （支持 `.tif/.tiff/.edf/.cbf`，可多选）
2. **确定几何**：处理本实验室第 1 批数据时，软件内置的标定（`lmfp1_lab6`）
   直接可用；新批次或动过探测器，用随批拍的 LaB₆ 标样图在 [校准] 页标定
   一次（[保存为配置] 存下来，整批通用）。
   **几何不对，积分出来的峰位整体就是偏的**——所以先做这一步。
3. **出图**：勾选文件 → 顶部 [1D] 入口 → [出图（已勾选 N 项）]
   —— 2θ 范围、点数保持默认即可；如需修改，在右侧参数面板中调整
4. **导出**：文件区 [导出数据] → 选择输出目录 → 导出 txt / 全部数据总表

（细则——处理、对比、热图、每种导出选项——都在随包《使用说明》里。）

**文件位置**
- 导出的数据：导出对话框中显示的目录（Windows 默认 `文档\XRD_Toolkit`，
  Mac 默认 `个人文件夹/XRD_Toolkit`），路径可在对话框中自行修改
- 计算过的曲线缓存：上述目录中的 `_stage` 子文件夹（可删，只是下次重算）

请提供以下两项：

1. **`XRD_Toolkit` 文件夹里的 `crash-watch.txt`**（程序记录崩溃现场的文件，
   Windows 在 `文档\XRD_Toolkit\`，Mac 在 `个人文件夹/XRD_Toolkit/`）
2. 出问题那一刻的**界面截图**（若程序右下角"日志"区有红色报错行，请一并截入）

## 数据与隐私

- **所有计算都在你本机完成**：程序不联网、不上传数据、没有使用统计。
- `crash-watch.txt` 是崩溃现场记录，可能含本机路径；对外分享前请先自行查看。
- 科研工具免责：结果取决于几何标定与参数选择，**发表/交付前请人工复核**关键数值。
- 许可：本程序采用 MIT 许可；随附第三方组件（Qt/PySide6、pyFAI、NumPy、
  SciPy、Matplotlib 等）的许可全文在包内 `THIRD_PARTY_NOTICES.txt`，
  程序内 **帮助 → 关于 → 第三方许可** 也可打开。

## 已知限制

- 未做系统签名：Windows 首次"仍要运行"、Mac 首次"右键→打开"（见上）
- 暂无自动更新：新版本发布后重新下载覆盖安装即可（缓存与配置不会丢失）
- 系统要求：macOS 13 起 / Windows 10 起
- 界面中文、图内文字英文（图片可直接用于论文）；导出数据为英文表头
- 通用原位页的峰窗只能在方案 JSON 里配置；趋势/汇总/报告图固定显示
  晶胞 a、c（b 在 CSV 与单帧报告里）
- 原位批量暂不精修仪器峰形、原子坐标/占位或多主相；少数相晶胞只作趋势参考
