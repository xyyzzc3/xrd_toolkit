# XRD Toolkit v0.1.4 试用版

不用装 Python、不用配环境：下载 → 解压 → 双击。

> **0.1.4（本次）**：一版"数据处理更讲究、看图更清楚"的更新——**对比 / 热图
> 加了栅栏**：只画已经算好的曲线，还没做过 1D 积分的原始数据会被拦下并在
> 日志里点名（先点 [1D] 出图，再回去对比）；对比图新增**色标**——一条颜色
> 刻度把"哪个颜色是哪条数据"读出来（「对比」页勾 [显示色标]，说明文字和
> 摆放的角落都能在 [外观…] 里改）；对比配色新增期刊常用的**「经典色」**
> （Okabe–Ito 八色，色盲友好）和**「彩虹」**（瀑布同款顺序色，平铺不堆叠时
> 相邻曲线更好认）；**自动扣背景修好一处硬伤**（个别数据行会"饿死"、对比与
> 热图上在 1.75° 附近冒出断点——现在不会了，旧的背景产物会自动重算一次）；
> 进**全屏不再把参数栏收走**；**[删除所有缓存] 点一下就删**；瀑布图修两处
> （少数曲线整条丢失、先缩放后调行距错位）；对比图**取消堆叠后视图能回来了**；
> **出图之前**调好的显示参数不再在出图瞬间丢；常见报错（系统拦读、文件不在、
> 图片损坏……）都补了人话和对策；校准图也能**放大、按 [复位视图] 回家**。
> 另外新增 **XRD 模拟模块**：从晶体结构文件（CIF）算出理论粉末 XRD 图谱，
> 适合对照实验数据（可选安装）。
> 已在用旧版本的用户直接下载覆盖安装即可，标定、缓存与配方均会保留
> （旧背景算法算的产物会自动重算，不影响原始数据）。

## 安装与第一次打开

三个平台的应用均**未做系统签名**，所以第一次打开时系统会拦截一次——
这属于预期现象，按下面步骤操作一次即可，之后不再提示。

**Windows**
1. 把 `XRD-Toolkit-windows.zip` 解压到任意文件夹（建议解压到桌面或 D 盘）
2. 进入解压出来的 `XRD Toolkit` 文件夹，双击 **`XRD Toolkit.exe`**
3. 如果出现蓝色窗口"Windows 已保护你的电脑" → 点 **更多信息** → 点 **仍要运行**
   （若没有"更多信息"按钮：右键 `XRD Toolkit.exe` → 属性 → 勾选底部的
   「解除锁定」→ 确定 → 再运行）

**Mac（Intel 或苹果芯片都一样）**
1. 把 zip 解压，得到 **XRD Toolkit.app**（可以拖进"应用程序"文件夹）
2. **第一次请勿直接双击**——要 **右键点它（或按住 Control 点）→ 选「打开」**
3. 弹窗里再点一次 **打开**。此后即可正常双击

## 快速上手

1. **打开数据**：左上「文件」区 → [打开…] → 选中仪器导出的 `.tif` 图像
   （支持 `.tif/.tiff/.edf/.cbf`，可多选）
2. **确定几何**：处理本实验室第 1 批数据时，软件内置的标定（`lmfp1_lab6`）
   直接可用；新批次或动过探测器，用随批拍的 LaB₆ 标样图在 [校准] 页标定
   一次（[保存为配置] 存下来，整批通用）。
   **几何不对，积分出来的峰位整体就是偏的**——所以先做这一步。
3. **出图**：勾选文件 → 顶部 [1D] 入口 → [出图（已勾选 N 项）]
   —— 2θ 范围、点数保持默认即可；如需修改，在右侧参数面板中调整
4. **导出**：文件区 [导出数据] → 选择输出目录 → 导出 txt / 全部数据总表

（细则——处理、对比、热图、每种导出选项——都在随包《使用说明》里。）

**文件位置**
- 导出的数据：导出对话框中显示的目录（Windows 默认 `文档\XRD_Toolkit`，
  Mac 默认 `个人文件夹/XRD_Toolkit`），路径可在对话框中自行修改
- 计算过的曲线缓存：上述目录中的 `_stage` 子文件夹（可删，只是下次重算）

- `crash-watch.txt` 是崩溃现场记录，可能含本机路径；对外分享前请先自行查看。
- 科研工具免责：结果取决于几何标定与参数选择，**发表/交付前请人工复核**关键数值。
