# XRD Toolkit 0.1 试用版

不用装 Python、不用配环境：下载 → 解压 → 双击。

## 下载哪个？

| 你的电脑 | 下载这个 |
|---|---|
| Windows 10 / 11 | **XRD-Toolkit-windows.zip** |
| Mac（苹果芯片：M1/M2/M3/M4…） | **XRD-Toolkit-macos-apple-silicon.zip** |
| Mac（Intel 处理器） | **XRD-Toolkit-macos-intel.zip** |

分不清 Mac 是哪种芯片：左上角  →「关于本机」，看"芯片"或"处理器"一行——
写着 Apple M** 就选苹果芯片，写着 Intel 就选 Intel。

> 安装包约 110 MB（里面是整个计算环境：Python、pyFAI、Qt 界面框架）。
> 第一次启动会多花几秒到十几秒（系统安全检查 + 首次建字体缓存），
> 之后就正常了。

## 安装与第一次打开

三个平台的应用都**没有花钱做系统签名**，所以第一次打开时系统会拦一下——
这是正常现象，按下面点一次就行，以后不再问。

**Windows**
1. 把 `XRD-Toolkit-windows.zip` 解压到任意文件夹（建议解压到桌面或 D 盘）
2. 进入解压出来的 `XRD Toolkit` 文件夹，双击 **`XRD Toolkit.exe`**
3. 如果出现蓝色窗口"Windows 已保护你的电脑" → 点 **更多信息** → 点 **仍要运行**

**Mac（Intel 或苹果芯片都一样）**
1. 把 zip 解压，得到 **XRD Toolkit.app**（想放"应用程序"文件夹就拖进去）
2. **不要直接双击**——第一次要 **右键点它（或按住 Control 点）→ 选「打开」**
3. 弹窗里再点一次 **打开**（按钮第二次会出现）。以后就可以正常双击了

## 三步上手

1. **打开数据**：左上「文件」区 → [打开…] → 选中仪器导出的 `.tif` 图像
   （支持 `.tif/.tiff/.edf/.cbf`，可多选）
2. **出图**：勾上文件 → 顶部 [1D] 入口 → [出图（勾选文件）]
   —— 2θ 范围、点数默认就好；要改在右侧参数面板
3. **导出**：文件区 [导出数据] → 选输出目录 → 导出 txt / 全部数据总表

**几何配置**：内置了一条本实验室第 1 批的标定（`lmfp1_lab6`）。自己批次的
几何有两条路——用 LaB₆ 标样在 [校准] 页标一套（[保存为配置] 存下来），
或者拿到别人给的工具导出的 `.poni` 文件在参数面板 [加载参数…] 导入。

**文件去哪了？**
- 导出的数据：导出弹窗里显示的目录（默认在 `文档\XRD_Toolkit`（Windows）
  或 `个人文件夹/XRD_Toolkit`（Mac）），弹窗里的路径可以自己改
- 算过的曲线缓存：上面那个目录里的 `_stage` 子文件夹

## 出问题怎么办

把这两样发给我：
1. **`XRD_Toolkit` 文件夹里的 `crash-watch.txt`**（程序记录崩溃现场的文件，
   Windows 在 `文档\XRD_Toolkit\`，Mac 在 `个人文件夹/XRD_Toolkit/`）
2. 出问题那一刻的**界面截图**（程序右下角"日志"区如果有一行红字/报错，
   一起截上）

## 0.1 已知限制

- 没做系统签名：Windows 首次"仍要运行"、Mac 首次"右键→打开"（见上）
- 没有自动更新：出新版我会在群里说，重新下载覆盖即可（缓存和配置不会丢）
- 系统要求：macOS 13 起 / Windows 10 起
- 界面中文、图内文字英文（论文用图直接可截）；导出数据是英文表头
